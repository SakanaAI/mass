# Third-party software and data

MASS uses Qwen models and qwen-code, Harbor, ScienceAgentBench, MLR-Bench,
PyTorch, Transformers, PEFT, and other dependencies obtained from their public
upstream sources. Their licenses remain applicable; this repository does not
relicense them. Upstream notices remain in the downloaded checkouts.

The ScienceAgentBench data archive is obtained separately from its official
source. Model weights, task datasets, and generated experiment artifacts are
not distributed with this source repository.

No public open-source license has been assigned to the MASS-specific code in
this repository.
